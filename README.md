# dsaLeetCode

My LeetCode solutions in Python, plus hand-rolled implementations of basic data structures.

Many problems have more than one solution. `one.py` is usually the first, straightforward approach, and `two.py` / `third.py` are later or more optimal ones. Most solutions have a docstring explaining the idea behind them.

## Repository layout

```
.
├── dsaBasicImplementations/   # stack, queues and deque built from scratch
├── easy/                      # one folder per problem
│   └── twoSum/
│       └── one.py
├── medium/
└── hard/                      # coming soon
```

Each problem folder is named after the method in LeetCode's `Solution` class (`twoSum`, `maxArea`, ...).
